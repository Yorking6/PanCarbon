# 量化方法学（抽象参考）

本文件定义方法族、单位契约与口径规则。所有数值（因子、汇率、热值、GWP、阈值）由运行时注入，本文件不含数值。

## 1. 三类量化途径

| 途径 | 适用 | 输出 |
|---|---|---|
| 直接测量 | 连续监测、烟气/流量计量 | 浓度 × 流量 → 排放量 |
| 质量平衡 | 化学反应、物料投入产出 | 输入碳 − 输出碳 − 库存变化 |
| 排放因子法 | 绝大多数活动数据 | `ad × ef × gwp / scale` |

统一主公式：

```
tco2e = ad * ef * gwp / scale
```

- `ad`：归一化后的活动数据，单位见 `normalized.unit`。
- `ef`：排放因子，单位见 `factor_library.factors[].unit`。
- `gwp`：由因子库 `gases` 与配置 `gwp_version` 决议；单一 CO2e 因子时为 1。
- `scale`：**显式量纲除数**，必须来自因子库该项的 `scale` 字段，由「ad 单位 × ef 单位」推导。禁止在代码里写常量分母；历史事故多源于此（多除或少除一次量级）。

量纲检查：计算前必须确认 `normalized.unit` 与因子 `unit` 的分母可约；不可约时该行 `tco2e = null` 并记 WARN，禁止静默填 0 或猜测换算。

## 2. 范围三方法族

| 方法键 | 说明 | 典型 ad | 常见换算链 |
|---|---|---|---|
| `supplier_specific` | 供应商特定/摇篮到大门数据 | 采购量或供应商提供排放量 | 供应商数据校验、单位归一 |
| `spend_based` | 支出法/EEIO | 采购金额 | 万元→元、本币→因子币种（汇率表）、×EEIO 因子 |
| `average_data` | 平均数据法/重量法 | 物料重量 | 重量单位归一、物料类别映射 |
| `distance_based` | 距离法 | 吨公里 | 重量×距离、运输方式映射、费用→里程 |
| `hybrid` | 混合法 | 部分实物量 + 部分金额 | 分段记录每条换算链 |
| `wtt` | 上游燃料与能源相关活动 | 燃料量/电量 | WTT 因子、输配电损失、避免与 S1/S2 重复 |
| `mass_balance` | 质量平衡 | 投入/产出物料 | 化学计量、碳含量 |

每个 `results.lines[]` 必须记录所用 `method`，且同一 `row_id` 若存在多方法结果，必须分属不同 `versions[]`，仅一个版本可为 `final`。**不同方法得出的结果不得相加**（例如支出法与重量法对同一采购的两种估算）。

### 常见换算链（须逐条留痕）

- `fee_to_volume`：加油/燃气费用 → 体积，需引用价格表 `reference` 与 `factor`。
- `fee_to_distance`：机票/铁路/出租车费用 → 里程，需引用折算规则与 `note`。
- `container_to_mass`：瓶数 × 规格 → 质量。
- `currency_conversion`：本币 → 因子币种，需引用汇率表与年份。
- `ratio_split`：按处置占比或抽样比例拆分/放大，需写明分母含义与样本量。
- `carry_over`：沿用既有结果，必须填 `carry_over_from` 与 `estimation_note`。

`conversion_chain[]` 每项含 `op`、`from_unit`、`to_unit`、`factor`、`reference`、`note`；缺 `note` 的换算视为不可追溯。

## 3. Scope 2 双口径

- `location_based`：按设施所在区域电网平均因子。
- `market_based`：按合同工具/绿证/直购电等市场化工具；`market_instruments[]` 须逐项登记工具类型、数量、来源、有效期与归属主体。
- 两套结果分别写入 `by_scope.S2` 对象的两个键；总量默认采用 `location_based`，差异须在报告中说明。
- 自发自用可再生能源、外购光伏等口径由配置声明因子取零与否，并单列，避免与外购电网电混算。
- 归属于其它范围的用电（如租赁资产能耗）必须从 S2 剥离并归入对应 S3 类别，剥离规则写入配置，保证跨年可比。

## 4. GWP 与气体

`gwp_version` 由配置注入；因子库每项声明 `gwp_version`；混合工质按组分配比加权计算，配比属因子库数据。同一运行结果内的 GWP 版本一致性由 Stage 7 校验。

## 5. 基准年与重算政策

`recalc_policy.base_year_recalc_trigger[]` 列出触发基准年重算的事件类型（边界变化、方法学变化、因子版本变化、发现重大差错、并购剥离等）。触发时须：
1. 生成新版本而非覆盖旧版本；
2. 记录 `method` 变更与 `note`;
3. 报告中说明可比性受影响；
4. 旧版本标记 `superseded`，唯一保留一个 `final`。

跨年比较只在方法学、边界、因子版本一致时进行；不一致时必须显式标注"不可直接比较"。

## 6. cut-off 与不涉及

`scope3.cutoff.rule` 与 `threshold_pct` 由配置注入，不得预设。排除某排放源须记录：排除理由、估算影响、审批人。禁止以 cut-off 名义掩盖数据缺口；所有缺口同时进入「数据质量与缺口说明」sheet。

## 7. 数据质量与不确定性

定性分级（分数表由 `org_config.quality.scores` 注入，禁止写死）：

- 活动数据等级 `X / Y / Z`（自动连续测量 / 定期量测 / 自行推估）。
- 排放因子等级 `A ~ F`（按来源权威性与匹配度）。
- 仪器校正等级 `L / M / S`。
- 单行平均分 = 三项分数均值；按该行排放量占比加权得总评分；等级阈值由 `quality.grade_thresholds` 注入。

不确定性采用定性分析，报告须说明评价方法与权重来源；阈值与等级名称全部由配置注入。

## 8. 期间口径

- `period.basis` 区分 `consumption`（消耗期间）、`billing`（计费周期）、`estimated`（估算）。
- 开票日期不等于消耗期间；跨自然月计费须显式记录 `billing_note`。
- 报告年归属以消耗期间为准；跨年部分按配置规则拆分或标注。
- 同一行不得同时混入多个期间口径。
