# 标准框架映射（抽象参考）

本文件只描述标准的结构与映射关系，不含任何组织数据、排放因子数值或报告年份。具体条款适用性由运行时配置与使用者判定。

## 1. 两套体系的并列关系

| 维度 | GHG Protocol 企业核算与报告准则 | ISO 14064-1 组织层级量化与报告 |
|---|---|---|
| 分类主轴 | Scope 1 / Scope 2 / Scope 3 | 类别 1~6 的直接与间接排放 |
| 合并方法 | 股权比例法 / 财务控制权 / 运营控制权 | 同上，需在报告中说明 |
| Scope 3 细分 | 上游/下游共 15 类 | 归入间接排放类别，需自行细分 |
| 报告年与基准年 | 要求可比性与重算政策 | 要求说明基准年与重算 |
| 保证 | 由 ISO 14064-3 等另行规定 | ISO 14064-3 规定核查/审定 |

两套分类必须能双向映射：`classification.json` 同时记录 `scope`、`iso_category`、`s3_category`，不得只保留一套。

## 2. Scope 与 ISO 类别

- **Scope 1（直接排放）**：固定燃烧源、移动燃烧源、工艺过程排放、逸散排放（含制冷剂、灭火剂等）、土地利用变化（若适用）。
- **Scope 2（外购能源间接排放）**：外购电力、外购热力、外购蒸汽、外购冷、外购压缩空气。须区分 location-based 与 market-based 两套结果。
- **Scope 3（其他间接排放）**：见下节 15 类。
- **ISO 14064-1 六类**：直接 GHG 排放与清除；输入能源的间接 GHG 排放；运输产生的间接 GHG 排放；组织使用产品产生的间接 GHG 排放；与组织产品使用相关的间接 GHG 排放；其它来源的间接 GHG 排放。

映射规则：ISO 的类别编号与 GHG Protocol 的 Scope 编号**不是**一一对应，禁止用编号直接换算；以排放源性质为准。

## 3. GHG Protocol 范围三 15 类（标识键 S3-1 ~ S3-15）

| 键 | 类别 | 上游/下游 | 常见活动数据 |
|---|---|---|---|
| S3-1 | 外购商品和服务 | 上游 | 采购金额、采购重量、物料类别、供应商特定数据 |
| S3-2 | 资本货物 | 上游 | 固定资产原值、资产类别、购置金额 |
| S3-3 | 燃料和能源相关活动（不含 S1/S2） | 上游 | 燃料量、外购电量、上游(WTT)因子、输配电损失 |
| S3-4 | 上游运输和配送 | 上游 | 货物重量、运输距离、运输方式、吨公里、运输费用 |
| S3-5 | 运营中产生的废物 | 上游 | 废弃物重量、处置方式占比、废水量 |
| S3-6 | 商务差旅 | 上游 | 舱位/里程、铁路里程、出租车里程、住宿间夜 |
| S3-7 | 员工通勤 | 上游 | 通勤方式、单程距离、出勤天数、抽样与总体人数 |
| S3-8 | 上游租赁资产 | 上游 | 租赁资产能耗、面积、租赁范围与边界 |
| S3-9 | 下游运输和配送 | 下游 | 出货重量、距离、运输方式、吨公里 |
| S3-10 | 售出产品的加工 | 下游 | 中间产品加工成本或活动量 |
| S3-11 | 售出产品的使用 | 下游 | 销量、使用寿命、使用阶段能耗 |
| S3-12 | 售出产品寿命终止处理 | 下游 | 售出产品材料构成与报废处置方式 |
| S3-13 | 下游租赁资产 | 下游 | 出租资产能耗、面积、租赁收入 |
| S3-14 | 特许经营权 | 下游 | 特许经营方活动数据 |
| S3-15 | 投资 | 下游 | 投资类型、行业、金额、持股或融资比例 |

**默认全列 15 类**：判为「不涉及」的类别必须写入 `scope3.not_applicable_reasons`，理由为空则该类别不得标为不涉及。cut-off 的使用必须记录规则与阈值，且不得用来掩盖未收集的数据。

## 4. 温室气体种类与 GWP

气体种类由 `org_config.gases` 注入，常见为 CO2、CH4、N2O、HFCs、PFCs、SF6、NF3。GWP 版本由 `org_config.gwp_version` 注入（AR4 / AR5 / AR6 等），GWP 数值属于因子库数据而非本 Skill 内置常量。因子库每项须声明其 `gwp_version`；不适用时填 `not_applicable`。同一运行结果中出现的 GWP 版本必须一致，否则 Stage 7 判 ERROR。

## 5. ISO 14064-3 核查要素（模式 B）

核查报告须覆盖：核查/审定目的、范围与边界、准则、保证等级（有限保证/合理保证）、实质性阈值、核查程序（风险评估、抽样、访谈、交叉核对、重新计算、现场走访）、发现与观察项、不符合项与整改、核查声明与签署。

责任边界：
- 由清册与 `results.json` 提供：被核查数据、边界、明细、重新计算结果、数据质量与缺口。
- 由授权人提供：保证等级、实质性、抽样计划、访谈记录、核查员与机构、结论与签署。
- **禁止自动生成**：核查声明、保证意见类型、「无重大错报」等结论性表述。无 `verification_signoff.json` 时只出草稿与占位符。

## 6. 报告准则引用

模式 A 概况表需列示所依据标准名称与版本（由配置注入），以及组织自定的量化与报告制度。模式 B 准则章节需列示核查所依据的标准与 GHG 量化准则。引用文字从 `assets/phrases.json` 取，禁止在代码中拼接带具体年份的标准号硬编码。
